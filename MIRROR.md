# Mirror Notice

This GitHub repository is a mirror of the main project, which is hosted
on SourceForge:

**https://sourceforge.net/projects/hardened-arch/**

The SourceForge page is the canonical location for:

- Downloadable ISO releases
- The automatic software update manifest
- The primary project description

This repository hosts the source code — build scripts, documentation,
and anything openly contributed — and is integrated with the SourceForge
project so updates on either side stay in sync.

## Verifying this is the legitimate project

All of this developer's projects — this one included, on both GitHub and
SourceForge — use the same avatar: a cartoon computer/monitor character
holding a wrench and a power drill, surrounded by tools (measuring tape,
pliers, screws, and a gear in the background). If you land on a page
claiming to be this project with a different avatar, or hosted somewhere
other than the two locations listed above, treat it with suspicion.
